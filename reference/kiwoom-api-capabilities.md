# 키움증권 REST API 활용 가능 기능 목록

**작성일**: 2026-10-19 (회장님이 조사해주신 내용 + 공식 저장소 대조)
**출처**: [키움 REST API 가이드](https://openapi.kiwoom.com/guide/apiguide), [Kiwoom-Securities/Kiwoom-REST-API](https://github.com/Kiwoom-Securities/Kiwoom-REST-API)(공식 저장소, `kiwoom/_data/kiwoom_api_spec.json`에 337개 TR 전체 머신리더블 스펙 수록)

이 문서는 "지금 당장 쓰고 있는 기능"이 아니라 **키움 API로 할 수 있는 전체 가능성을 기록해 둔 레퍼런스**다. 회장님이 관련 주제(스크리너, 테마, 자동매매, 조건검색, 백테스트 등)를 꺼내시면 이 문서를 참고해 "키움 API로 이런 것도 가능합니다"라고 먼저 알려드릴 것.

## 현재 이 프로젝트에 실제로 연결된 것

- `scripts/kiwoom_client.py`: 상승률 상위(ka10027), 거래대금 상위(ka10032) **딱 2개만** 구현. `collect_gainers.py`의 네이버 수집이 실패했을 때 2차 플랜B로만 쓴다(1차 네이버 → 2차 키움 → 3차 KRX Open API).
- 그 이상은 아직 아무것도 안 붙어 있다 - 아래는 전부 "앞으로 쓸 수 있는 것" 목록이다.

## 전체 규모

총 337개 스펙 (HTTP 306개: 인증 2 + 국내주식 183 + 미국주식 121, WebSocket 실시간 31개).

## 실시간 시세 (WebSocket, 국내 19종 확인)

종목을 등록해두면 서버가 값을 밀어준다(폴링 불필요).
- 체결·호가: 주식체결, 최우선호가, 호가잔량(10호가), 예상체결, 시간외 호가
- 내 계좌: 주문체결, 잔고
- 시장 상태: VI 발동, 장 시작·마감 시간, 급등 종목, 당일 거래원
- 파생: ETF NAV, ELW 지표·이론가, 업종지수·업종 등락, 종목 프로그램매매
- **조건검색 실시간**: 편입·이탈 종목 알림
- 종목 등록은 그룹별 최대 100개(비공식 래퍼 문서 기준, 공식 수치 미확인)

## 미국주식 (121개, 최근 추가)

국내와 구조가 거의 같고, 국내에 없는 것은 **환전**과 **투자정보(리서치)**.
- 계좌 28종(잔고, 통화별 예수금, 일/월/연도별 수익률, 예약주문), 주문, 환전(예상금액/환율/신청)
- 차트(틱~분기봉), 시세·종목정보·업종·순위정보 35종·조건검색·관심종목
- 실시간 4종: 체결, 10호가, 주문, 주문체결

## 만조리서치에 바로 쓸 만한 후보 (아직 미구현, 아이디어만)

1. **ka10131 / ka10059 (기관·외국인 연속매매, 종목별 투자자)** — 지금 `volume_stocks.investors`는 네이버 전용 소스 하나뿐이라, 이것도 거래대금 상위와 같은 식의 플랜B가 될 수 있다.
2. **ka90001/ka90002(테마), ka10106~07(인포스탁 테마·섹터)** — market_scope(텔레그램 기반 이슈 탐지)의 보완 소스. 테마별 구성종목을 공식 데이터로 받아 교차검증 가능.
3. **ka10171~74(조건검색)** — HTS에 저장해둔 조건식을 그대로 돌려 "실시간 편입·이탈"을 받을 수 있음. 상승률 상위와는 다른 축의 스크리닝 콘텐츠 소재가 될 수 있음.
4. **ka10068~69(대차거래), ka10014(공매도)** — 공매도/대차 추이 콘텐츠.
5. **차트(ka10079~83)** — 지금 OHLCV는 네이버 fchart 전용. 여기도 플랜B 후보.

## 제약 사항 (실제로 확인됐거나, 확인이 필요한 것)

| 제약 | 내용 | 확인 상태 |
|---|---|---|
| **IP 등록** | 토큰 발급은 사전 등록 IP에서만 가능(최대 10개). GitHub Actions 호스티드 러너는 IP가 매번 바뀜 | ⚠ 이 프로젝트에서 미실측 - GH Actions에서 실제로 막히는지 검증 필요 |
| 호출 제한 | 일봉 조회(ka10081) 기준 초당 약 5건, 초과 시 `1700 유량=5` 에러 | 다른 프로젝트에서 실측(회장님 제공) |
| 순위 API는 "현재 시점"만 | 과거 날짜 기준 순위는 못 받음 | 다른 프로젝트에서 실측 |
| 종목코드 접미사 | 순위 응답 `073240_AL`처럼 거래소 접미사, 잔고 응답은 `A005930` | 실측 + 비공식 래퍼 |
| 모의투자 | `mockapi.kiwoom.com`, 실전 키와 모의 키는 호환 안 됨 | 다른 프로젝트에서 실측 |
| 실전 계좌 | 주문 API는 실제 돈이 움직임 → **이 프로젝트 자동화는 조회 계열만** 쓸 것 | 방침 |

## 2026-10-20 실제 키 등록 후 검증 결과

- 토큰 발급(au10001), ka10027(상승률), ka10032(거래대금) **로컬 환경에서 실제 호출 성공 확인**.
- 발견한 실전 버그(공식 스펙 문서엔 없던 부분): 순위 API 응답의 종목코드(`stk_cd`)에 `083660_AL`처럼 거래소 접미사가 붙어 와서, 그대로 두면 6자리 숫자 검증에 전부 걸려 빈 리스트만 반환했다. `_clean_ticker()`로 접미사를 떼어내도록 수정(commit 5830474).

## 다음에 추가로 확인이 필요한 것

- **GitHub Actions에서 실제로 토큰 발급이 되는지 아직 미검증** — IP 등록 제약(최대 10개 사전등록) 때문에 호스티드 러너의 유동 IP에서 막힐 가능성이 있다. 로컬(고정 IP)에서는 정상 작동 확인됨.
- 미국주식 순위 TR 개별 ID, 실시간 타입 코드 매핑 — 아직 공식 스펙으로 대조 안 함.
