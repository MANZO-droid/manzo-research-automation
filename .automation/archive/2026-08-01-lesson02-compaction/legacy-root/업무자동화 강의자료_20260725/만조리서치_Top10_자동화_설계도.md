# 만조리서치 Top10 종목 분석 자동화 — 설계도

작성일: 2026-07-25

## 업무
한국 증시 장 마감 기준 당일 주가 상승률 Top10 종목을 리스트업하고, 상승 이유와 차트를 분석해 만조리서치 홈페이지 '당일 상승률 상위 10위' 섹션에 매일 새 데이터로 반영한다. 토요일(또는 연휴 시 평일 다음 첫 휴일)에는 한 주간 상승률 Top10을 같은 방식으로 같은 섹션에 반영한다.

현재 불편: 클로드코드 스케줄로 자동화를 시도했지만 한 번도 끝까지 자동 완료된 적이 없어 매번 수동으로 마무리해야 했다. 원인 중 하나는 무료 운영 중 제미나이 토큰 소진.

## 시작 신호
- 평일: 한국시간 17시(장 마감 후) 자동 시작 — 확인된 사실
- 주말/연휴: 새벽 6시 자동 시작 — 확인된 사실
- 실행 도구: 클로드코드 스케줄 기능 — 확인된 사실
- 확인 필요: "토요일과 이어진 앞선 요일이 휴일인 연휴면 평일 다음 첫 휴일 기준"이라는 조건을 스케줄 트리거가 어떻게 자동 판별할지 (휴장일 캘린더 연동 등) 미확정

## 입력자료
- Top10 선정·차트 데이터: 한국투자증권 API, 키움증권 API, 필요 시 pykrx — 확인된 사실
- 상승 이유: 네이버 등 포털에서 종목당 최소 10개 이상 뉴스 크롤링 후 분석 — 확인된 사실
- API 키 등 인증 정보 보관 위치: `E:\AI 스터디\만조그룹 2차` 폴더 내 — 확인된 사실
- 확인 필요: 정확히 어떤 파일(.env 등)에 있는지, Git에 커밋되지 않도록 되어 있는지

## 현재 단계
클로드코드 스케줄로 전체 자동화를 시도 중이나, API 오류·제미나이 토큰 소진 등으로 중간에 멈추고 사용자가 매번 수동으로 최종 완료까지 처리하고 있음. 자동으로 끝까지 완료된 적은 없음.

## AI 역할
AI가 맡을 후보 단계 (확인된 사실):
- Top10 종목 자동 추출 (우선주, 관리종목, ETF, 정리매매 종목 자동 제외)
- 뉴스 기반 상승 이유 분석 (자동, 게시 전 사람 검토 없이 진행)
- 차트 생성 (자동)
- 홈페이지 게시까지 자동 (게시 후 사후 검토 방식)

확인 필요: "게시"에 git push 등 실제 배포 행위까지 AI가 수행하는 것을 의미하는지 명확히 정할 것. 이 프로젝트는 배포 = git push 구조이므로, 이 결정이 사람 검토 시점과도 직결됨.

## 필요 도구
확인된 사실:
- 한국투자증권 API, 키움증권 API 연동 완료
- pykrx 사용 가능
- 네이버 등 포털 뉴스 크롤링
- 스케줄 실행: 클로드코드 스케줄 기능
- 작업 폴더: `E:\AI 스터디\만조그룹 2차`

참고 사항 (코드베이스 CLAUDE.md 기준, 사용자 확인 필요):
- market-scope-data.json, stock-analysis-data.json, index.html '당일 상승률 상위 10위' 섹션
- git push → Vercel 자동배포

확인 필요:
- 제미나이(Gemini) API를 어느 단계(상승 이유 분석 등)에 쓰고 있는지, 무료 한도 초과 시 대안(다른 무료 모델, 재시도 로직 등)
- 뉴스 크롤링 대상 사이트의 이용약관/저작권 관련 확인 여부

## 사람 검토
확인된 사실:
- 검토 시점: 최종 게시(배포) 이후 사후 검토
- 검토 항목: 상승 이유 분석의 사실관계, 상승 이유/차트 설명 분량(250자 이상), 종목 필터링 누락·오류
- 오류 발견 시: 사용자가 어느 부분을 수정할지 지시하고, 수정 후 재배포

제안: 뉴스 콘텐츠의 출처 표기·저작권 이슈도 사후 검토 항목에 포함할지는 별도 검토 권장 (규정/개인정보/외부발송 관련 사항).

## 결과물
확인된 사실: 일간·주간 결과 모두 홈페이지 동일한 '당일 상승률 상위 10위' 섹션에 반영됨.

확인 필요: 일간 데이터와 주간 데이터를 사용자가 구분해서 볼 수 있어야 하는지, 아니면 그냥 덮어써도 되는지.

## 성공 기준
확인된 사실:
- 성공: 사람 개입·수정 없이 10개 종목 정리가 완벽하게 게시까지 완료
- 중단(사람 개입 필요) 조건: 제미나이 토큰 소진, API 오류, 필터링 후 종목 10개 미만, 권한 설정이 필요한 경우

## 다음 최소 단위
Top10 필터링 로직만 떼어내어, 우선주·관리종목·ETF·정리매매 종목을 제외한 Top10이 오류 없이 자동으로 완성되는지 먼저 검증한다.
