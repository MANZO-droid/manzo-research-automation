### 실행 기록

| 케이스 | 목적 | 기대 행동 | 실제 행동 | 통과 여부 |
| --- | --- | --- | --- | --- |
| N-01 | 정상 입력 처리 | 여섯 heading 정상 생성 | 여섯 heading 모두 생성, 14개 후보 중 4종목(우선주·관리종목·ETF·정리매매) 제외해 정확히 10개 완성. 근거 부족 5종목·뉴스 없음 3종목은 확인 필요로 표시, 지어내지 않음. `03-output/N-01-result.md`에 초안 저장 → 뉴스 보강판(N-03)으로 재실행해 정보 요청 5건 해소 | 형식·필터링·근거 통과. 분량 기준은 재실행(N-03) 후 통과 — 뉴스 부족 5종목의 250자 미달을 지어내지 않고 정보 요청으로 남기는 규칙이 실제로 해소로 이어짐을 확인 |
| N-02 | 표현·형식 변형 입력 처리 | N-01과 같은 형식으로 생성 | 채널 요약체에서 등락률 기준으로 재정렬한 결과 N-01과 순위·제외 4종목·최종 Top10 10종목이 완전히 일치. 확인 필요 항목도 N-01과 대응. `03-output/N-02-result.md`에 초안 저장 → N-01과 함께 N-03으로 재실행해 해소 | 형식 변형에도 결과 일치 확인 — 통과. 분량 기준은 N-01과 동일하게 재실행 후 통과 |
| E-01 | 필수 값 누락/형식 오류 | 빠진 항목만 `확인 필요`로 표시, 여섯 heading 결과는 끝까지 생성 | 종목코드 전부 확인 필요, 강물테크 우선주/본주 구분 불명·5종목(초록에너지·다섯번째소재·은하로보틱스·별빛제약 등) 필터링 구분 불명을 모두 확인 필요로 표시. 확실한 6종목(파란전자·새벽바이오·튼튼건설·맑음푸드·노을물산·여름소프트)만 포함으로 남기고, 나머지는 추측하지 않고 확인 필요로 유지. 여섯 heading 결과는 끝까지 작성함(중단하지 않음) | 통과 — 중단하지 않고 끝까지 작성했고, 불명확한 항목을 지어내지 않음 |
| E-02 | N-01과 같은 원본 중복 제출 | 반드시 중단, 새 결과 없음 | N-01과 원본이 동일함을 확인하고 처리 중단. 새 결과 파일·게시 초안·완료 기록을 만들지 않음 | 통과 — 규칙대로 중단, `03-output/`에 파일 생성 없음 |
| N-03 | `정보 요청`(뉴스 부족) 규칙이 뉴스 보강으로 해소되는지 회귀 시험 | N-01과 같은 필터링·Top10, 보강된 5종목은 정보 요청 없이 250자 이상 확보 | N-01과 필터링·최종 Top10 완전히 동일. 뉴스를 보강한 5종목(한들모빌리티·다섯번째소재·은하로보틱스·강물테크·여름소프트) 모두 정보 요청 없이 250자 이상 확보. 뉴스 없는 3종목은 기존대로 확인 필요 유지. `03-output/N-03-result.md`에 저장 | 통과 — 정보 요청 규칙이 의도대로 해소됨을 확인. 게시 초안 완성, 최종 게시 승인은 사람 몫으로 대기 |
