## 표에서 다루지 않은 것

- 실제 입력을 실행해 만조리서치 자동화의 개인 결과물이 처음 생겼을 때 정확히 어떤 파일명 규칙을 쓸지는 설계도에 없어 확인 필요로 남았습니다.
- 외부 도구(Slack 등) 연결을 대기하는 동안 생기는 파일은 없습니다. 연결 조건이 모두 채워지기 전에는 파일을 만들지 않습니다.
