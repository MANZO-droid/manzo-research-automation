# 02-reference

승인된 **기준·양식·참조 자료**만 두는 폴더입니다. 여기 파일은 "정답"이 아니라 결과물을 만들거나 검토할 때 기준으로 삼는 자료입니다.

## 지금 들어있는 것

- `output-contract.txt` — 공통 샘플(가상 Top10 상승 종목 자동화)의 결과 작성 기준. 여섯 heading(한 줄 요약/Top10 정리/상승 이유 요약/확인 필요/게시 초안/사람 검토·게시 확인)을 정의합니다. 강의 `강의자료/common-sample-pack/`의 원본을 그대로 복사했습니다.
- `복습요약-보고서-양식.html` — 복습요약 보고서를 채우는 **원본 양식**입니다. 복사해서 실제 값으로 채웁니다.
- `복습요약-보고서-양식.pdf` — 위 HTML 양식이 어떤 모양으로 나와야 하는지 확인하는 **기준**입니다. 이 PDF 자체를 고치지 않습니다.
- `workspace-file-guide.md` — 각 폴더에 어떤 파일이 어떤 상황에 생기는지 안내하는 표입니다.

## 만조리서치 자동화의 실제 기준

- `manzo-output-contract.md` — `scripts/collect_gainers.py` 코드에서 실제로 확인한 출력 규격(분량 200자/600자 기준, Gemini에게 전달되는/안 되는 값, 사람 검토 체크리스트). 확인 필요였던 우선주·관리종목·ETF·정리매매 제외 규칙은 **아직 코드에 없음** — 확인 필요 상태 그대로 남아있습니다(`design/automation-blueprint.md` 참고).
