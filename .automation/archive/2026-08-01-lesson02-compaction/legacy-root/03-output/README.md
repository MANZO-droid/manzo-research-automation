# 03-output

실행마다 만든 **결과물 초안**만 두는 폴더입니다. 보고서 HTML·PDF·ZIP, 게시 초안 등이 여기 쌓입니다. 이 폴더의 파일은 실행 결과일 뿐, 실제 외부 반영(홈페이지 배포 등)은 이 폴더에 저장한다고 저절로 일어나지 않습니다.

## 지금 생기는 것 (공통 샘플, 가상)

- `N-01-result.md` — N-01(표 형식 Top10 원시 자료) 입력을 `output-contract.txt` 기준으로 처리한 결과 (2026-07-25 — 게시 보류·정보 요청)
- `N-02-result.md` — N-02(텔레그램 채널 요약 형식) 입력을 같은 기준으로 처리한 결과 (2026-07-25 — 게시 보류·정보 요청)
- `N-03-result.md` — N-03(뉴스 보강 회귀 시험) 입력을 처리한 결과 (2026-07-25 — 정보 요청 해소 확인, 게시 초안 완성·사람 승인 대기)

## 만조리서치 자동화의 개인 결과물 (확인 필요)

Top10 종목 리스트, 상승 이유 요약, 차트 이미지, `market-scope-data.json`/`stock-analysis-data.json`에 반영할 최종 데이터 등을 이 폴더에 초안으로 먼저 둘지, 아니면 저장소 루트의 해당 JSON 파일에 바로 반영할지는 확인 필요입니다. 실제 홈페이지 배포(`git push`)는 사람이 검토·승인한 뒤에만 진행합니다.
